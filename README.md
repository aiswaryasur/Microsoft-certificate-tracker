🚀 Microsoft CertiHub
Learn. Practice. Get Certified.

An interactive, responsive web application designed to guide learners through Microsoft Learn pathways with real-time progress tracking and dynamic AI-powered step explanations.

🌟 Highlights
🧭 Domain Pathways: Structured learning paths across AI & Data Science, Cloud Computing, Cybersecurity, and Development.

📊 Analytics & Tracker: Real-time percentage progress bars and dedicated completion monitoring across individual domains and overall learning goals.

✨ Gemini AI Recommendation Engine: Context-aware explanations provided after each course completion to explain why the next step is recommended.

🔐 User Auth Flow: Front-end authentication system (Sign Up / Log In simulation) with dynamic user profile state management.
